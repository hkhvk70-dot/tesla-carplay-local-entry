# tepla 0.2.1 直装版使用指南

tepla 将无线 CarPlay 接收、网页显示、触控和免 root 本地入口放在一个 Android App 中。日常使用只需 Android 手机、iPhone 和特斯拉；画面与触控走手机热点内网，Android 移动数据用于热点联网，没有公网视频中继。

## 准备设备

- Android 9 或以上的 **ARM64** 手机，具备蓝牙、Wi-Fi 和可上网的个人热点。32 位 Android 和 x86 不支持本安装包。
- Android 手机插入可上网的 SIM，开启移动数据。先确认它自己的浏览器能打开网页。
- iPhone 开启 Wi-Fi 和蓝牙；Tesla 将加入 Android 手机的同一个系统热点。
- 热点最大连接设备数至少 **3**，名称和密码保持稳定。手机后台省电设为无限制，并允许前台服务运行。

此前 Xiaomi 17 Pro Max / Android 16 与 2025 Model 3 Performance AWD / 2026.26.200.11 的本地网络方案已显示和触控成功。**0.2.1 当前通过构建、签名和包内容检查，尚未完成新包的首次安装及实车全流程验收。** 其他手机、车机和后续系统版本须实测，免 root 入口依赖设备的 VPN 接口行为。

## 首次安装与连接

1. 下载 APK，用 Android 文件管理器打开，由系统安装器完成安装。若提示安装来源权限，按安装器提示允许本次使用的来源。**0.2.1 已内置现有实验认证材料，不需要另找认证 ZIP。**
2. 如已有 WheelPlay、旧 tepla 或独立「CarPlay 本地入口」，先在这些 App 中停止服务。同一时刻只运行一个 CarPlay 接收端和本地入口；旧 App 与数据可保留。
3. 在 Android 系统设置中开启移动数据、蓝牙和普通个人热点，至少允许 3 个客户端。热点名称、密码和频段稍后必须与 tepla 中填写的一致。
4. 在 Android 的系统蓝牙设置中与 iPhone 配对，按两端提示确认。首次系统蓝牙配对仍需手动完成。
5. 打开 tepla，点「开始设置」。保存热点信息，选择系统已配对的 iPhone。附近设备、录音、通知等权限出现时，按连接功能的提示处理。
6. 点「连接并启用入口」。保持 iPhone 的 Wi-Fi、蓝牙开启，允许 iPhone 弹出的 CarPlay 请求；无线连接会使用已填写的 Android 热点。等首页显示 CarPlay 已连接，并完成系统 VPN 授权，使「本地入口」显示已开启。该 VPN 提供本机访问地址。
7. Tesla 连接 Android 的同一热点。车机浏览器完整输入 **`http://7.7.7.1:8080/`**，包括 `http://` 和 `:8080`；首次输入 tepla 首页当前网页配对码，再点「启动显示」。
8. 在停车状态检查画面、应用点击和地图拖动。网页默认沉浸显示，右上角菜单可恢复工具栏；Tesla 自己的浏览器栏由车机管理。

7.7.7.1 在本方案中是手机的临时本地地址别名，不是向某台公网服务器上传画面。系统热点仍使用系统分配的网段，不需要改网关或 root。

拒绝权限或取消连续设置会停止向导推进，已保存的信息保留。处理好系统设置后，返回 tepla 再点主按钮；系统授权不会由软件代替确认。

## 音频

默认声音由 Android 手机输出。可把 Android 手机通过蓝牙连接 Tesla，并在车机选择相应蓝牙音源。

想测试网页发声，在 tepla「连接设置 → 音频」选择「车机浏览器」，随后在车机网页点按画面允许播放。浏览器未就绪、暂停或断流时会回退手机输出。该网页音频路径尚未完成本版实车验收，音乐、导航、通话和 Siri 需分别验证。

## 日常恢复、停止和回退

1. 手机重启后先解锁，恢复移动数据、蓝牙和系统热点。
2. 打开 tepla，确认保存的热点信息仍与系统一致，点击主按钮恢复 CarPlay 和入口。
3. Tesla 重新加入热点并打开或刷新浏览器收藏的地址，必要时重新输入当前配对码。
4. 「服务管理 → 停止入口」保留 CarPlay；「停止全部服务」停止接收、网页和入口。系统热点由系统管理，不自动关闭。
5. 回退旧方案时先停止 tepla 全部服务，再打开原接收端和独立入口。无需清数据或删除系统蓝牙配对。

本版没有开机自动启用热点或 VPN。不要同时运行其他 VPN；它们会争用 Android 的活动 VPN 位置。

## 常见问题

| 症状 | 处理顺序 |
| --- | --- |
| iPhone 刚加入热点就断开 | 检查热点最大连接数至少 3；不要让电脑占满名额；核对系统与 App 的名称、密码；先停旧接收端再连接 |
| Tesla 提示无法访问互联网 | 先检查 Android SIM 移动数据和网页访问；使用可上网的系统热点；手机不要依赖 iPhone 自己的热点作为上游 |
| 找不到 Wi-Fi | 检查系统热点已开启；可尝试改为 2.4 GHz，同时在 tepla 更新频段。改连接设置前先停止全部服务 |
| 一直等待 iPhone | 检查系统蓝牙配对、Wi-Fi/蓝牙、权限和热点信息；只保留一个接收端；停止全部服务后重新点击连接，暂不清配对 |
| 车机网页打不开 | 确认 Tesla 仍连同一热点、本地入口已开启；核对完整 HTTP 地址；关闭其他 VPN 后重新启动入口 |
| 页面打开但黑屏 | 先确认 CarPlay 已连接，点网页「启动显示」；退出占用会话的其他浏览器；停止会话后可改 JPEG 试画面与触控 |
| 卡顿或后台断流 | 设置后台省电无限制、保持前台服务；保持固定画面比例，关闭旧 App；处理热点掉线，再比较 WebRTC 与 JPEG |
| 重启后地址失效 | 解锁手机、恢复热点、打开 tepla 重新连接和授权；入口是临时运行状态 |

更多历史症状和证据范围见 [40 项踩坑记录](PITFALLS.zh-CN.md)。该文档包含旧双 App 的按钮名称，使用 tepla 时以本指南为准。
